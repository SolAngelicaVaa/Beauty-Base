# 💄 BeautyBase

> An interactive community forum built for beauty enthusiasts to share advice, discuss trends, and curate their favorite products and columns.

Developed as a **University Project**, BeautyBase provides a space where users can engage in discussions, customize their profiles, and save content they love.

---

## ✨ Features

* 👤 **User Authentication & Profiles:** Register, log in, manage profile settings, and upload profile pictures.
* 💬 **Community Forum & Threads:** Create new discussion threads, post replies, edit, or delete your posts.
* 💖 **Favorites & Saved Content:** Bookmark your favorite products, posts, and columns for easy access.
* 💅 **Makeup API Integration:** Fetch and display real-time makeup products and trend details. (Currently not functioning) 
* 🔒 **Password Recovery:** Secure password reset and email check functionality. (Reset safe in the web browser, email is currently down)

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **APIs:** Makeup API integration (`makeup_api.php`)
